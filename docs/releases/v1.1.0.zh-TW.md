# v1.1.0 開發規劃

[English](v1.1.0.md) | **繁體中文**

## 目標

將目前縮減版的 O-A0003-001 資料模型擴充成完整、已驗證的觀測資料契約，再用乾淨的雙語 GIS 呈現，而不是把所有數字全部堆在地圖上。

## 資料範圍

v1.0.0 已經呼叫 O-A0003-001，但目前 Parser 只保留少部分欄位。v1.1.0 將保存目前真實 API station schema 中已驗證且具應用價值的欄位。

### 測站與地理資訊

- StationName / StationId
- ObsTime.DateTime
- WGS84 經緯度
- CoordinateName / CoordinateFormat
- StationAltitude
- CountyName / TownName
- CountyCode / TownCode

### 即時氣象

- Weather
- VisibilityDescription
- SunshineDuration
- Now.Precipitation
- WindDirection / WindSpeed
- AirTemperature
- RelativeHumidity
- AirPressure
- UVIndex

### 風資訊

- Max10MinAverage.WindSpeed
- Max10MinAverage.Occurred_at.WindDirection
- Max10MinAverage.Occurred_at.DateTime
- GustInfo.PeakGustSpeed
- GustInfo.Occurred_at.WindDirection
- GustInfo.Occurred_at.DateTime

### 當日高低溫

- DailyHigh temperature + 發生時間
- DailyLow temperature + 發生時間

## Data Contract 規則

- 實作前重新取得最新真實 API response 驗證 schema。
- 保留 CWA 原始資料語意與單位。
- Leaflet 使用 WGS84。
- 已知 missing / abnormal sentinel 在 application boundary 正規化。
- UI 不直接顯示 `-99`、`-98`、`990`、`X` 等技術值。
- Raw weather data 與 UI 翻譯分離。
- 擴充 SQLite 前先更新 sanitized fixture 與 Parser tests。

## GIS 資訊架構

資料完整，不代表每個欄位都要成為地圖圖層。

### 主要地圖圖層

1. Temperature 溫度
2. Humidity 濕度
3. Precipitation 降水
4. Wind 風
5. Pressure 氣壓
6. UV Index 紫外線
7. Weather 天氣

一次只啟用一個主要 observation layer。

### Station Detail Panel

點選測站後顯示結構化詳細資料。

**Current Conditions / 目前狀況**
- 天氣
- 溫度
- 濕度
- 降水
- 氣壓
- UV
- 能見度
- 日照

**Wind / 風**
- 目前風向 / 風速
- 最大十分鐘平均風與發生時間
- 最大瞬間陣風風速 / 風向 / 時間

**Today / 今日**
- 當日最高溫 + 發生時間
- 當日最低溫 + 發生時間

**Station / 測站**
- 測站名稱 / ID
- 縣市 / 鄉鎮
- 行政區代碼
- 高度
- 座標
- 觀測時間

## 畫面美感方向

```text
Full-screen Map
+ 精簡 Top Status Bar
+ 右側 Layer Panel
+ Contextual Legend
+ Station Detail Drawer / Card
```

- 地圖維持主體。
- 顏色集中在 active metric。
- Metric card spacing / typography 統一。
- 不把所有值直接塞在 marker。
- 採 progressive disclosure：先 overview，點測站再看 details。
- Mobile 將 details 改成 bottom sheet / compact overlay。
- Attribution 永遠保持可見。

| 資料 | 建議呈現 |
| --- | --- |
| 溫度 | sequential color + numeric marker |
| 濕度 | blue/cyan scale + % |
| 降水 | blue scale，> 0 強調 |
| 風 | 風速顏色 + 小型方向箭頭 |
| 氣壓 | restrained sequential scale |
| UV | Low → Extreme 分級 |
| 天氣 | 簡潔 condition symbol |

## 英文 / 繁體中文 UI

支援：

```text
en
zh-TW
```

維持 Vanilla TypeScript，採用小型 typed translation dictionary，不導入大型 i18n framework。

建議：

```text
web/src/i18n/
├── locale.ts
├── en.ts
└── zh-TW.ts
```

翻譯範圍包括 page title、layer names、legend、station details、loading / empty / error states、日期時間格式與語言選擇器。語系偏好可放 localStorage。

數值資料不翻譯；localization 只處理 presentation。

## Gate Re-entry

v1.1.0 會修改 Parser、SQLite、JSON contract、Frontend types 與 GIS UI，因此最早受影響 Gate 是 Gate 1。

```text
Gate 1 → Gate 2 → Gate 3 → Gate 4 → Gate 5
```

### Gate 1
- 重新檢查最新 O-A0003-001 真實 response。
- 更新 sanitized fixture。
- 擴充 Parser 與 tests。

### Gate 2
- 擴充 SQLite schema / UPSERT。
- 用 real integration data 驗證新增欄位。
- 擴充 JSON export 與 tests。
- 維持 idempotent rerun。

### Gate 3
- 擴充 WeatherObservation。
- 新增 metric formatting / classification tests。
- 新增資料 layers 與 Station Detail UI。
- 加入 English / Traditional Chinese locale。
- 兩種語言都完成 Manual Verification。

### Gate 4
- 完整 Pester、Frontend Tests、Production Build。
- Clean checkout 與文件 parity。

### Gate 5
- Deploy 新版。
- Production 驗證兩種語言、所有 layers、Station Detail、missing values 與 scheduled data refresh。

## Definition of Done

- 已驗證的 O-A0003 欄位完整經過 Parser → SQLite → JSON。
- Frontend types 與新版 contract 一致。
- Temperature / Humidity / Precipitation / Wind / Pressure / UV / Weather layers 可用。
- 其他欄位在 Station Detail 有清楚資訊層級。
- English / Traditional Chinese UI 完整。
- UI 不直接顯示 CWA 技術 sentinel。
- v1.1.0 release commit 的 Gate 1–5 全部完成驗證。
